# Day 01 - Offensive and Defensive Security

## Offensive Security

Offensive Security involves finding and exploiting vulnerabilities in systems to improve security.

Examples:
- Penetration Testing
- Red Teaming
- Vulnerability Assessment

## Defensive Security

Defensive Security focuses on detecting, monitoring, and responding to cyber threats.

Examples:
- SOC Operations
- Incident Response
- Threat Hunting

## Key Learning

Understanding both offensive and defensive perspectives helps build a stronger cybersecurity foundation.
